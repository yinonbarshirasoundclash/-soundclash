# אתר Soundclash — מדריך הפעלה והעלאה

אתר סטטי מלא, כתוב בקוד, ללא וויקס וללא מערכת ניהול. תשע דפים, עיצוב מותאם לנייד,
וקובץ אחד לעריכת הופעות.

## 1. מה יש בחבילה

```
index.html            דף הבית
90s.html              דף נחיתה — Soundclash ניינטיז
80s.html              דף נחיתה — Soundclash אייטיז
y2k.html              דף נחיתה — Soundclash Y2K
tv-vs-film.html       דף נחיתה — סדרות נגד סרטים
shows.html            הופעות קרובות (נטען מ-shows.json)
gallery.html          גלריה מלאה + וידאו
about.html            אודות הלהקה וההרכב
contact.html          טופס הזמנה + כל דרכי הקשר

shows.json            ← הקובץ היחיד שצריך לערוך כדי לעדכן הופעות
build.py              מחולל האתר: כל התוכן והקישורים יושבים כאן
assets/css/site.css   כל העיצוב
assets/js/site.js     תפריט, גלריה, טופס, טעינת הופעות
sitemap.xml, robots.txt   לגוגל
.nojekyll             קובץ ריק שמונה מגיטהאב לעבד את האתר. לא למחוק
```

**לראות את זה עכשיו:** לפתוח את `index.html` בדפדפן. הכל יעבוד, כולל התמונות והווידאו.

## 2. דומיין — ההמלצה

בדקתי חמישה שמות. אלה שלא מפנים לשום שרת, כלומר יש סיכוי טוב שהם פנויים:

| דומיין | הערכה |
|---|---|
| **soundclash.co.il** | **ההמלצה הראשונה.** קצר, מדויק, וסיומת ישראלית שמאותתת למפיק מקומי שזו להקה מקומית. |
| soundclash.band | חלופה יפה ובינלאומית, אבל פחות מוכרת לקהל ישראלי |
| soundclash.live | מתאים לתוכן, קצת גנרי |
| soundclashband.com | **תפוס** — הדומיין מפנה לשרת קיים |

**איפה קונים .co.il:** דרך [רשם ישראלי כמו Domain The Net](https://www.domainthenet.com) או
[Ionos](https://www.ionos.co.il). מחיר טיפוסי — כמה עשרות שקלים לשנה.
**איפה קונים .com / .band:** [Cloudflare Registrar](https://www.cloudflare.com/products/registrar/)
מוכרים במחיר עלות, בלי התייקרות בשנה השנייה. זו האופציה הזולה לאורך זמן.

לפני הרכישה — לוודא זמינות בפועל בדף החיפוש של הרשם. "לא מפנה לשרת" זו אינדיקציה, לא הוכחה.

## 3. אחסון — GitHub Pages, חינם, מהדפדפן

יש לך כבר חשבון גיטהאב, ולאתר הזה **גיטהאב הוא הבחירה הנכונה** — לא רק "גם אפשר".
ההסבר בסוף הסעיף. אין צורך להתקין Git ואין צורך בשורת פקודה; הכל דרך האתר של גיטהאב.

### שלב א׳ — יצירת המאגר והעלאת הקבצים

1. ב-[github.com/new](https://github.com/new) ליצור מאגר בשם `soundclash`.
   **חשוב: לבחור Public.** בתוכנית החינמית של גיטהאב, Pages עובד רק ממאגר ציבורי
   (מאגר פרטי דורש GitHub Pro). לאתר תדמית זה לא מפריע — כל התוכן ממילא נועד להיות גלוי.
   לא לסמן שום תיבה של README/gitignore/license — שיישאר ריק.
2. במסך שנפתח ללחוץ **uploading an existing file**.
3. **לפרוס את ה-ZIP במחשב, ולגרור את כל התוכן** (כולל התיקייה `assets`) אל החלון.
   כרום תומך בגרירת תיקיות שלמות.
4. למטה ללחוץ **Commit changes**.
5. בחבילה יש גם קובץ ריק בשם `.nojekyll`. קבצים שמתחילים בנקודה מוסתרים בסייר הקבצים,
   ולכן ייתכן שהוא לא ייגרר. אם הוא לא הועלה — ליצור אותו ידנית: במאגר **Add file →
   Create new file**, להקליד בשם `.nojekyll`, להשאיר את התוכן ריק, ו-**Commit**.
   תפקידו למנוע מגיטהאב לנסות לעבד את האתר כבלוג. עשר שניות, פעם אחת.

### שלב ב׳ — הדלקת האתר

1. במאגר: **Settings → Pages** (בתפריט הצדדי).
2. תחת **Source** לבחור **Deploy from a branch**, ואז ענף `main` ותיקייה `/ (root)`.
   **Save.**
3. להמתין דקה-שתיים ולרענן. בראש הדף תופיע הכתובת החיה:
   `https://<שם-המשתמש-שלך>.github.io/soundclash/` — האתר באוויר.

### שלב ג׳ — חיבור הדומיין

1. **Settings → Pages → Custom domain**, להקליד `soundclash.co.il` ו-**Save**.
   גיטהאב יוצר לבד קובץ בשם `CNAME` במאגר — לא למחוק אותו.
2. בלוח הבקרה של רשם הדומיין להוסיף **ארבע רשומות A** לדומיין הראשי (@):

   ```
   185.199.108.153
   185.199.109.153
   185.199.110.153
   185.199.111.153
   ```

   ולמי שרוצה גם IPv6, ארבע רשומות AAAA:

   ```
   2606:50c0:8000::153
   2606:50c0:8001::153
   2606:50c0:8002::153
   2606:50c0:8003::153
   ```

3. ובנוסף רשומת **CNAME** עבור `www` שמצביעה אל `<שם-המשתמש-שלך>.github.io`
   (בלי שם המאגר בסוף).
4. לחזור ל-**Settings → Pages** ולסמן **Enforce HTTPS**. התיבה עשויה להיות אפורה עד
   24 שעות בזמן שגיטהאב מנפיק את תעודת ה-SSL — זה תקין, פשוט לחזור מאוחר יותר ולסמן.

### שלב ד׳ — לעדכן את האתר אחר כך

להיכנס למאגר, ללחוץ על הקובץ שרוצים לשנות, ללחוץ על **עיפרון העריכה**, לערוך, ו-**Commit changes**.
האתר מתעדכן תוך פחות מדקה.

### למה גיטהאב ולא Netlify, במקרה הזה

הסיבה היא **`shows.json`**. זו הפעולה שתחזור על עצמה יותר מכל דבר אחר באתר, ובגיטהאב היא
נראית כך: נכנסים למאגר, לוחצים על `shows.json`, לוחצים על העיפרון, מוסיפים את ההופעה,
שומרים. **זה עובד גם מהטלפון.** בדרך של Netlify (גרירה ידנית) היית צריך לפתוח מחשב,
לערוך את הקובץ מקומית ולגרור מחדש את כל התיקייה — בשביל שורה אחת.

ההפרשים האחרים זניחים לאתר בגודל הזה: שניהם חינם, שניהם עם SSL אוטומטי ו-CDN,
ולשניהם מגבלות שאתר תדמית לא מתקרב אליהן (בגיטהאב: 1GB למאגר ורוחב פס רך של 100GB בחודש).

היתרון האחד שהיה ל-Netlify — טפסים מובנים — כבר לא רלוונטי: הטופס באתר עובד עם Formspree
או נופל לוואטסאפ, ושניהם עובדים על כל אחסון שהוא.

## 4. הפעלת הטופס (חמש דקות, פעם אחת)

הטופס באתר עובד כבר עכשיו — הוא פשוט נופל אוטומטית לוואטסאפ עם כל הפרטים שמולאו.
כדי שהוא ישלח גם מייל:

1. להירשם חינם ב-[formspree.io](https://formspree.io) עם `Stageart.pnima@gmail.com`.
2. ליצור **New Form**, לקרוא לו "Soundclash".
3. הם נותנים כתובת כמו `https://formspree.io/f/xayzbqwe`. **המזהה הוא החלק האחרון** — `xayzbqwe`.
4. לפתוח את `assets/js/site.js`, ובשורה השלישית מלמעלה למלא:
   ```js
   formspreeId: "xayzbqwe",
   ```
5. לשמור, ולהעלות את הקובץ המעודכן לגיטהאב (או לערוך אותו ישירות שם דרך העיפרון).
   הפניות מגיעות למייל, וכפתור הוואטסאפ נשאר כגיבוי.

התוכנית החינמית מכסה 50 פניות בחודש — יותר ממספיק.

## 6. איך מעדכנים הופעות

לפתוח את `shows.json` ולהוסיף בלוק:

```json
{
  "date": "2026-11-14",
  "venue": "שם המקום",
  "city": "עיר",
  "time": "21:30",
  "format": "Soundclash ניינטיז",
  "note": "",
  "tickets": "https://www.goshow.co.il/..."
}
```

- התאריך תמיד בפורמט `שנה-חודש-יום`.
- **הופעות שהתאריך שלהן עבר נעלמות מהאתר לבד.** אין צורך למחוק ידנית.
- שדות ריקים פשוט לא מוצגים.
- אחרי עריכה — לשמור בגיטהאב. **אין צורך להריץ את `build.py`** בשביל עדכון הופעות.
- אפשר לערוך את הקובץ ישירות באתר גיטהאב, גם מהטלפון: המאגר → `shows.json` → עיפרון → Commit.

הרצועה בראש דף הבית ("ההופעה הקרובה: …") מתמלאת מאותו קובץ, ונעלמת לבד כשאין תאריכים.

## 7. לניתוק מלא מוויקס

התמונות באתר עדיין נטענות מה-CDN של וויקס. זה עובד, אבל אם תסגור את חשבון הוויקס — הן ייעלמו.
לנתק לגמרי:

1. להוריד את תשע התמונות מהכתובות שרשומות בסעיף 2 של `build.py`.
2. לשמור אותן בתיקייה `assets/img/` בשמות פשוטים באנגלית.
3. ב-`build.py`, להחליף את `W = "https://static.wixstatic.com/media/"` בשורה `W = "assets/img/"`,
   ולעדכן את שמות הקבצים ברשימה `IMAGES`.
4. להריץ `python3 build.py` ולהעלות מחדש לגיטהאב.

בונוס: זה גם יאיץ את האתר.

## 8. הבחירות העיצוביות — ומאיפה הן

האתר בנוי לפי מחקר שפת רוקוויל שנעשה בפרויקט:

- **פתיחה מוסדית, לא "היי".** דף הבית פותח ב"Soundclash מציגה פורמט מופע שבו…", והסופרלטיב
  מוצמד לרפרטואר ("הלהיטים הגדולים ביותר של העידן") ולא ללהקה.
- **המנגנון מתואר בשמות עצם ובפעלים פיזיים**, לא בתארים — בדיוק כמו פסקת החומה של פינק פלויד
  אצל רוקוויל. ארבעה שלבים: הזירה נפתחת, שיר מול שיר, הקהל מכריע, הכרזה ופרסים.
- **מספרים קשיחים בכל מקום אפשרי**: 6 נגנים, 2 סולנים, 4 זירות, 90 דקות, 4–6 שבועות אספקה.
- **פירוט ההרכב בשמות ובתפקידים, מופרד בקווים אנכיים** — בשורת "הרכב" שבמפרט, בכל דף.
  לפי המחקר זה החלק הכי משכנע באתר של רוקוויל, ודווקא הכי יבש.
- **ארבע הזירות מוצגות כמשפט קטגוריה ואז רשימת שמות** ("מופעי קרב לארבע זירות שונות: ניינטיז,
  אייטיז, Y2K, וסדרות נגד סרטים") — הפתרון של רוקוויל לבעיית "זה נראה כמו תפריט".
- **בגוף כל דף פורמט אין אזכור לפורמטים האחרים.** המשפחה חיה בניווט ובפוטר בלבד.
- **משפט "מ… ועד ל…"** בראש כל דף זירה, בתבנית של MissBehave — מצייר את גבולות הערב בלי רשימת שירים.
- **CTA בשם פעולה + מספר טלפון**, אף פעם לא שאלה מהוססת.

ומה **לא** נכנס, לפי אותם גבולות: אין טענת ותק, אין ספירת מופעים, אין שמות לקוחות או המלצות,
אין מיצוב "מובילים בתחום", אין השוואה לאף מתחרה, ואין הבטחת תוצאה. כל מספר באתר הוא מספר אמיתי.

## 9. פרטים טכניים

- **אפס תלויות.** אין React, אין jQuery, אין CDN חיצוני חוץ מגופני גוגל ונגן היוטיוב.
- **עובד גם בלי JavaScript** — למעט רשימת ההופעות, שיש לה הודעת נפילה עם מספר טלפון.
- **נגישות:** ניווט מקלדת מלא, `focus-visible` על כל אלמנט לחיץ, `alt` על כל תמונה,
  וכיבוד `prefers-reduced-motion`.
- **SEO:** תגיות `title` ו-`description` ייחודיות לכל דף, תגיות Open Graph לשיתוף בפייסבוק
  ובוואטסאפ, `sitemap.xml`, ו-Schema.org מסוג MusicGroup בדף הבית.
- **נבדק** ב-1400px וב-390px: אין גלישה אופקית ואין שגיאות JavaScript באף דף.
